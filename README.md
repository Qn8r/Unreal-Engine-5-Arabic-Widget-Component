# Arabic World Text Component

An Unreal Engine 5 plugin for displaying correctly shaped Arabic text in world space.

## English

### Features

- Arabic shaping and right-to-left layout.
- Blueprint actor and component.
- Full or yaw-only camera facing.
- Readable text from both sides.
- Alignment, wrapping, background, and shadow settings.
- Arabic and English editor interface.
- 16 Arabic font families under the SIL Open Font License 1.1.
- No external runtime dependencies.

### Installation

1. Copy the `ArabicWidget` folder to `YourProject/Plugins`.
2. Open Unreal Engine and enable the plugin from **Edit > Plugins**.
3. Add `Arabic Widget Text Actor` to the level, or add the component to a Blueprint.
4. Enter the text and choose the font, direction, and camera-facing mode.

## العربية

إضافة لأنريل إنجن 5 لعرض النص العربي بشكل صحيح داخل عالم اللعبة.

### المميزات

- تشكيل عربي وكتابة من اليمين إلى اليسار.
- ممثل ومكوّن للبلوبرنت.
- مواجهة كاملة أو أفقية للكاميرا.
- نص مقروء من الجهتين.
- خيارات للمحاذاة والتغليف والخلفية والظل.
- واجهة عربية وإنجليزية.
- 16 عائلة خطوط عربية بترخيص OFL 1.1.
- لا تحتاج إلى إضافات خارجية.

### التثبيت

1. انسخ مجلد `ArabicWidget` إلى `YourProject/Plugins`.
2. افتح أنريل إنجن وفعّل الإضافة من **Edit > Plugins**.
3. أضف `Arabic Widget Text Actor` إلى الخريطة، أو أضف المكوّن داخل البلوبرنت.
4. اكتب النص واختر الخط والاتجاه وطريقة مواجهة الكاميرا.
