# الاستخدام

## بداية سريعة

1. ضع `Arabic Widget Text Actor` في المستوى.
2. اكتب النص من قسم `Content`.
3. اختر الخط والاتجاه ومواجهة الكاميرا.

يمكن أيضاً إضافة `Arabic Widget Text` لأي Actor من Blueprint.

للتعديل وقت اللعب استخدم:

- `Set World Text`
- `Set Face Camera Mode`
- `Set Two Sided Mode`
- `Refresh World Text`

## غرفة التجربة

ضع `Arabic Widget Demo Room` في أي مستوى، وتُبنى الغرفة تلقائياً.

الغرفة تعرض كل الخطوط الـ16، وتستخدم `Engine Cube` وخامة المحرك فقط.

الدعم المؤكد حالياً: Unreal Engine 5.8.1 على Win64.
