# الاختبار

نجاح البناء، واختبارات الأتمتة، والفحص المرئي في PIE، واختبار اللعبة المعبأة
بوابات إصدار مستقلة.

## الاختبارات الآلية

شغّل مجموعة الاختبارات `ArabicWidget`. تتحقق المجموعة من:

- إنشاء المكوّن وقيمه الافتراضية.
- بقاء قيمة `FText` العربية سليمة عبر واجهة Blueprint.
- تعطيل التصادم والملاحة وTick على الخادم المخصص.
- دوال تغيير مواجهة الكاميرا والرسم ثنائي الوجه.
- تحميل جميع أصول Font وFont Face المرفقة.

## مصفوفة الاختبار المرئي

اختبر الحالات التالية في PIE وفي نسخة Development معبأة:

- اتصال الحروف العربية واللام ألف.
- الحركات والعلامات القرآنية بخط يدعمها.
- علامات الترقيم والأرقام العربية والهندية.
- نص عربي وإنجليزي مختلط.
- كل خط مرفق باستخدام عينة النص نفسها.
- تعدد الأسطر والالتفاف التلقائي.
- المحاذاة إلى اليمين والوسط واليسار.
- الاتجاه التلقائي وRTL وLTR والاتجاه حسب لغة اللعبة.
- الخلفيات الشفافة والمعتمة.
- الوجه الخلفي المعكوس والوجه الخلفي المقروء.
- مواجهة الكاميرا الكاملة وYaw Only ووضع الإيقاف.
- التحديث من Blueprint وقت التشغيل.
- أقصى مسافة للرسم.
- أكثر من لاعب محلي عند استخدام `Player Index`.

## اختبار التثبيت النظيف

ابنِ حزمة الإضافة، وانسخها إلى مشروع C++ نظيف، ثم فعّلها وأعد بناء المشروع.
ضع الـActor في مستوى، وبعدها كرر اختبار PIE الأساسي.
