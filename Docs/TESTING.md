# الاختبار

شغّل مجموعة `ArabicWidget` من Automation.

الاختبارات تتأكد من:

- إعدادات المكوّن والنص العربي.
- تحميل الخطوط الـ16.
- غرفة العرض وخريطة التجربة.
- استخدام الغرفة لأصول المحرك فقط.

قبل النشر جرّب الخريطة في PIE ونسخة Development معبأة. افحص RTL، النص
المختلط، الالتفاف، الوجهين، مواجهة الكاميرا وتغيير النص من Blueprint.
